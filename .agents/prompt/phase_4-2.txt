Phase 4.2 Task: Implement Scenario Comparison Engine

Objective:
Create a dedicated analysis module (src/analysis.rs) that compares two Mortgage instances side-by-side (e.g., standard baseline vs. accelerated extra-payment loan) and calculates interest saved, time saved, and total cash outflow difference.

Code Requirements:

1. Create src/analysis.rs:
- Define ComparisonReport struct:
  #[derive(Debug, Clone, PartialEq)]
  pub struct ComparisonReport {
      pub baseline_months: u32,
      pub accelerated_months: u32,
      pub months_saved: u32,
      pub years_saved: f64,
      pub baseline_interest: f64,
      pub accelerated_interest: f64,
      pub interest_saved: f64,
      pub baseline_outflow: f64,
      pub accelerated_outflow: f64,
      pub total_outflow_saved: f64,
  }

- Implement pub fn compare_mortgages(baseline: &Mortgage, accelerated: &Mortgage) -> ComparisonReport:
  * Sum total interest and total_outflow from baseline.schedule and accelerated.schedule.
  * Calculate months_saved = baseline_months.saturating_sub(accelerated_months).
  * Calculate years_saved = months_saved / 12.0.
  * Calculate interest_saved and total_outflow_saved.

- Add unit tests in src/analysis.rs:
  * Test that comparing a loan with extra payments to a standard loan correctly reports positive months saved and interest saved.

2. Update src/display.rs:
- Implement pub fn print_comparison_report(report: &ComparisonReport, baseline_title: &str, accel_title: &str):
  * Render a clean side-by-side comparison summary box in the terminal displaying baseline vs accelerated stats and total savings.

3. Update src/main.rs:
- Add `mod analysis;`.
- Create a standard mortgage and an accelerated mortgage (with extra principal payments).
- Call compare_mortgages and print_comparison_report to display the scenario comparison in the terminal.

Verification:
- Run cargo test to verify all tests in analysis.rs pass.
- Run cargo run to verify the comparison output table formatting.
