Phase 4.1 Task: Implement Annual Aggregation Summary

Objective:
Add year-by-year rollup capabilities to our Rust mortgage calculator engine. Group the monthly schedule entries into annual buckets (Year 1, Year 2, etc.) to show yearly totals for principal, extra principal, interest, escrow, total cash outflow, and year-end balance.

Code Requirements:

    src/mortgage.rs

    Define the AnnualSummary struct:

#[derive(Debug, Clone, PartialEq)]
pub struct AnnualSummary {
pub year: u32,
pub principal_paid: f64,
pub extra_principal_paid: f64,
pub interest_paid: f64,
pub escrow_paid: f64,
pub total_outflow: f64,
pub year_end_balance: f64,
}

    Implement pub fn annual_summaries(&self) -> Vec inside impl Mortgage:

        Calculate payment_year = ((m - 1) / 12) + 1 for each month m in self.schedule.

        Accumulate monthly figures (principal, extra, interest, escrow, total_outflow).

        Push an AnnualSummary entry whenever a year completes or when the schedule ends early due to extra payments.

        Track year_end_balance accurately from the last month of each year.

    Add unit tests inside mod tests in src/mortgage.rs:

        Verify that a 15-year loan generates 15 annual summaries when no extra payments are made.

        Verify that summing interest across all AnnualSummary structs matches the total interest in self.schedule.

        Verify that early payoff (e.g. via extra payments) correctly reduces the total number of annual summaries without panicking.

    src/display.rs

    Implement pub fn print_annual_summary_table(mortgage: &Mortgage):

        Call mortgage.annual_summaries().

        Render a clean, formatted table in the terminal displaying Year, Principal, Extra Paid, Interest, Escrow, Total Outflow, and End Balance.

    src/main.rs

    Import print_annual_summary_table from display.

    Demonstrate the annual summary table output after running the mortgage scenarios.

Verification:

    Run cargo test to ensure all new unit tests pass.

    Run cargo run to verify terminal table layout and formatting.
